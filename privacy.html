Privacy Policy

Hermes DGX · Last updated: 18 September 2026

This Privacy Policy describes how Hermes DGX ("the application"), a private single-user automation assistant, handles information obtained through Google APIs. The application is operated solely by its owner, for the owner's own use.

1. Scope

The application is used exclusively by its operator on the operator's own Google Account. It is not distributed, published to any marketplace, or made available to any other person. There are no end users other than the operator.

2. Information the application accesses

With the operator's explicit OAuth consent, and only for the operator's own Google Account, the application may access:

  • Gmail messages, threads and labels (read, modify, send);
  • Google Calendar events;
  • Google Drive files, Google Docs documents and Google Sheets spreadsheets;
  • Google Contacts (read-only);
  • Basic Google Account identity (email address), used solely to identify the authorized account.

3. How information is used

Accessed information is used solely to perform tasks the operator explicitly requests on the operator's own device — for example summarizing the operator's unread email, preparing an overview of upcoming calendar events, or reading and writing a document the operator asks about. The application does not profile users, does not perform marketing analysis, and does not derive advertising data from this information.

4. Storage and retention

OAuth access and refresh tokens are stored on the operator's own device and are never transmitted to any party other than Google's APIs. Data fetched from Google APIs is held only in memory or in transient local caches needed to complete a requested task, and is not retained in any external database or cloud service. Tokens and caches can be deleted at any time (see Section 7).

5. Sharing and disclosure

No data is sold, rented, transferred or otherwise shared with any third party. No data obtained from Google APIs is used to train, fine-tune, or evaluate machine-learning models, and none is made available to advertising platforms. Google API data is not transferred to any party except as required by law. The application does not use Google API data to determine creditworthiness or for lending purposes.

6. Security

All communication with Google takes place over TLS, and no service other than Google's own APIs ever receives token material. There is no shared server-side component, and no data belonging to any other person is processed by this application.

7. Revoking access and deleting data

The operator can revoke the application's access at any time at myaccount.google.com/permissions, which immediately invalidates the stored tokens. Deleting the locally stored credential files removes all data associated with the application.

8. Limited Use disclosure

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes to this policy

Any change to this policy will be published on this page together with an updated revision date.

10. Contact

Questions about this policy may be raised through the project page: github.com/snowpeak77/hermes-dgx-oauth.
