Hermes DGX

A private, single-user automation assistant — not a public or commercial service.

What this application is

Hermes DGX is a personal automation agent running on a privately owned workstation. It serves exactly one user: its owner. It is not offered to the public — there is no sign-up, no third-party users, and no multi-tenant service behind it.

Why it requests Google account access

The agent performs tasks for its owner on the owner's own Google Account, using OAuth 2.0 with the owner's explicit consent. Typical uses:

  • Gmail — read unread mail and send messages on the owner's behalf (for example a daily morning briefing).
  • Google Calendar — list upcoming events for scheduling and meeting preparation.
  • Google Drive / Docs / Sheets — search, read, upload and update the owner's own documents.
  • Contacts — read-only lookups to resolve names to email addresses.

OAuth tokens stay on the owner's own device and are never transmitted to any server other than Google's own APIs.

Privacy

No data is collected, aggregated, sold or shared with any third party. See the Privacy Policy for details, including the Limited Use disclosure.
